Export myworkdayjobs.com jobs to CSV

Export jobs from a myworkdayjobs.com career site to CSV or Excel, including how to get past the unofficial 2,000-job list cap.

Workday career sites do not offer a "Download CSV" button. The page is a JavaScript app. The jobs themselves are loaded from an unofficial CXS endpoint the site already calls, with no login and no API key on a typical public board:

POST https://{tenant}.{wdN}.myworkdayjobs.com/wday/cxs/{tenant}/{site}/jobs

Body: {"appliedFacets": {}, "limit": 20, "offset": 0, "searchText": ""}. limit above 20 is often rejected. total is trustworthy on the first page only. Read the site's robots.txt before you request anything, identify yourself in the User-Agent, and space requests out.

A small export, and where it stops

For a board under 2,000 openings you can page offset by 20, write title, location, posted text and URL to jobs.csv, and stop when a page is short or you reach total. That is enough for many mid-size employers.

Three traps show up on large sites such as NVIDIA:

  • The list window stops at 2,000. Asking for offset: 2000 may repeat page one instead of returning an empty page. To go further you have to split by facets (appliedFacets) and deduplicate by job id.
  • The list row is thin. Pay ranges, the exact posting date and the full description usually need one detail request per job.
  • Shared cloud IPs get HTTP 429s. A script that treats a blocked response as "zero jobs" will write an empty spreadsheet and look finished.

The unofficial endpoint can change without notice. Do not build anything you cannot afford to repair. The deeper CXS notes are in the Workday jobs API guide.

FAQ

Can I export a Workday career site to Excel, not just CSV?

Yes. After a run, Apify's dataset export supports CSV, Excel and JSON. The rows are the same.

Why did my own script stop at 2,000 jobs?

That is the CXS list cap for a single query. Split by facet buckets and deduplicate, or use the Actor, which is built for that case.

Is this an official Workday API?

No. Workday does not document a public job-board API for third parties. The CXS route is what the career site itself uses, and it can break.
