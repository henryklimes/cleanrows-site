Website tech stack checker from a company domain

Check which CMS, analytics, chat and hiring tools a company website uses, from public page source, plus a hosted bulk checker.

A "website tech stack checker" looks at a public site and names the tools behind it: WordPress or Webflow, Google Analytics or Segment, Intercom, Shopify, a Greenhouse apply widget. Browser extensions do this one URL at a time. Bulk work needs a script.

What you can read without logging in

From the HTML, cookies, script hosts and a few response headers you can usually see:

  • CMS or site builder (wp-content, cdn.shopify.com, Webflow, Wix);
  • tag managers and analytics (googletagmanager.com, cdn.segment.com);
  • chat and support widgets;
  • sometimes the ATS, when the careers or apply flow loads greenhouse.io, lever.co, ashbyhq.com or myworkdayjobs.com.

This is a fingerprint, not a complete inventory. Server-side tools (the CRM, the data warehouse, the payroll system) do not show up in the marketing site. Treat the result as "signals published on the website," not "everything the company runs."

For a single URL, view-source and search for those hosts is enough. For a list of domains, you want the homepage plus Contact / Careers, and a consistent schema.

FAQ

Is this the same as BuiltWith or Wappalyzer?

Same idea, narrower output. Those products maintain large technology catalogues. This Actor records the stack signals it actually sees on the company's pages, together with contact and social fields, and does not claim a complete vendor inventory.

Can I check many URLs at once?

Yes. Paste a list of domains into the bulk tech-stack task. You pay per company, not per extra page fetched inside that company's site.

Will it see tools that only run behind login?

No. Only what the public site exposes.
