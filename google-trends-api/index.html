Google Trends API for bulk keywords, comparisons and Trending Now

How to pull Google Trends interest over time, interest by region, rising queries and Trending Now for many keywords, including comparisons of more than 5 terms.

Google Trends has no generally available official API. The website is fine for one-off checks. For a list of keywords, a weekly refresh, or a comparison that goes past Google's 5-term cap, you need a client that can talk to the same explore widgets the website uses.

What you can get

For each keyword and geography you can request:

  • Interest over time — a 0–100 series for the window you choose (for example the last 12 months).
  • Interest by region — the same 0–100 scale by country, region, city or DMA.
  • Related queries — top and rising queries, including Breakout terms.
  • Trending Now — around 10 current rising searches per country, with traffic and related news, from Google's public RSS feed.

Related topics exist in the interface but often come back empty for automated clients. Do not build a pipeline that depends on them.

The 5-keyword limit

The Trends explore UI lets you compare at most five terms, because they share one 0–100 scale. To compare 8 or 12 terms honestly, you run overlapping batches that include a shared anchor keyword, then rescale. That is easy to get wrong if you just stitch raw series together.

The Actor

Google Trends API – Bulk Keywords, Compare & Trending Now does the session handling, pacing (about one request per second per session), retries, and the compare-mode chaining. It costs $0.25 per 1,000 keyword-rows and $0.10 per 1,000 Trending Now rows, with no start fee.
