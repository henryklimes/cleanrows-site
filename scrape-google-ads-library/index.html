Scrape the Google Ads Library (Transparency Center)

How to scrape the Google Ads Library (Ads Transparency Center). There is no official commercial API; here is how to export ads for any country.

People search for a "Google Ads Library scraper" or "scrape Google Ads Transparency Center" because the Ads Transparency Center is a website, and they want the creatives as JSON or CSV. Google has also started calling the same corpus an ads library in places. The short answer: there is no official, general-purpose API for that website.

On 15 July 2024, in the Google Ads API forum, the Google Ads API team wrote that there is no API endpoint for the Ads Transparency Center. The Google Ads API covers your own advertiser account, not everyone else's ads. As of 25 November 2026 we have not seen a newer announcement of a public commercial API. A deeper look at the official dataset is in the Google Ads Transparency Center API guide.

What you can do without a scraper

  • Browse the Center by advertiser or domain, pick a country, and copy what you need by hand.
  • Query Google's BigQuery public dataset for advertisers that served ads in the European Economic Area or Turkey. It will not match a US-only or UK-only view of the website, and it does not give you the creative image or landing page the way the site does.

Exporting ads for any country

For a competitor in the US, or a lead list you want to check for active ads, the website is the source. Doing that in bulk means paging a JavaScript app that can change without notice.

Google Ads Library Scraper (Ads Transparency Center) is the Cleanrows Actor for that job. Paste a domain, a brand name or an advertiser ID. You get a check (is this company advertising, Google's ad-count range, the advertiser accounts) and, if you want them, one row per ad: format, first and last shown dates, an image or preview, and a link back to the Center. $0.50 per 1,000 ads and $2 per 1,000 checks, no start fee. Not-found lookups are free. Set maxAdsPerQuery to 0 to only run the check. To see who is advertising without pulling creatives, start from Check if a company runs Google Ads.

It does not extract ad copy text. Domain searches can include resellers whose ads point at that domain; use an advertiser ID when you want one account.

Example tasks:

  • Search the Google Ads Library by domain
  • Who runs Google Ads now (lead list check)
  • All ads of an advertiser, last 90 days
  • New Google ads since last run

FAQ

Is the Google Ads Library the same as the Ads Transparency Center?

Yes, for this purpose. It is the public library of Google ads at adstransparency.google.com. There is still no official commercial API for it.

Can I export the ads to CSV?

Yes. Run a task and use the dataset Export menu in Apify Console (CSV, Excel or JSON).

Can I limit the scrape to one country or format?

Yes. Tasks exist for the UK, the Czech Republic, image ads, video ads in Germany, and date windows such as the last 7 or 90 days. You can also set the region and format on the Actor input.
