Workable jobs API — public board postings as JSON

Workable's public widget endpoint returns a company's open jobs as JSON, with no API key. Here is the URL, what it returns, and a hosted feed if you also need Greenhouse, Lever or Ashby in the same schema.

Workable boards are public at https://apply.workable.com/{slug}/. The same slug talks to a widget API that needs no key:

GET https://apply.workable.com/api/v1/widget/accounts/{slug}?details=true

details=true includes each job's HTML description in the same response. Leave it off for a lighter list. The slug is the path segment in the careers URL (for Hugging Face, huggingface).

On 20 November 2026 this URL returned Hugging Face's live board (company name, six open jobs, titles, locations, departments and descriptions). An older path, /api/v3/accounts/{slug}/jobs, returned HTTP 404 on every board we tried the same day, including Hugging Face. Prefer the widget.

import requests

slug = "huggingface"
data = requests.get(
    f"https://apply.workable.com/api/v1/widget/accounts/{slug}",
    params={"details": "true"},
    timeout=20,
).json()

for job in data.get("jobs") or []:
    print(job["title"], job.get("published_on"), job.get("application_url"))

Useful fields, in our check of that board: title, shortcode, department, employment_type, telecommuting, city, state, country, a locations array (do not read only the first top-level city if you care about every office), published_on, application_url and description. We did not see a structured salary field; some postings mention pay only in the description.

The widget is built for an embed, not as a versioned developer API. Field names can change, and you have to normalize them yourself if you also read Greenhouse or Lever.

FAQ

Do I need a Workable API key to list a company's jobs?

Not for the public board. The widget endpoint is unauthenticated. Workable also has a private API for customers of a board; that is a different product.

How do I find the slug?

It is the path in apply.workable.com/{slug} or the subdomain in {slug}.workable.com. If the careers site is a custom domain, view source or the network tab for apply.workable.com.

Why did /api/v3/accounts/.../jobs return 404?

That path 404'd on the boards we requested on 20 November 2026. Use /api/v1/widget/accounts/{slug}?details=true instead.
