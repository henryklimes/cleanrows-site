Google Ads Transparency Center API — what exists, and what does not

There is no official API for the Google Ads Transparency Center. The free BigQuery dataset covers ads shown in the EEA or Turkey. Here is how to query that, and how to export ads for any country.

People search for a "Google Ads Transparency Center API" because the Ads Transparency Center is a website, and they want the same data as JSON. The short answer: there is no official, general-purpose API for that website.

On 15 July 2024, in the Google Ads API forum, the Google Ads API team wrote that there is no API endpoint for the Ads Transparency Center. The Google Ads API covers your own advertiser account, not everyone else's creatives. As of 20 November 2026 we have not seen a newer announcement of a public commercial API.

The official dataset: BigQuery, and only part of the map

Google does publish a BigQuery public dataset named bigquery-public-data.google_ads_transparency_center, with creative_stats and removed_creative_stats. You need a Google account and a GCP project. Queries can run under BigQuery's 1 TB/month free tier.

The catch is in Google's own overview: the tables cover advertisers that served ads in the European Economic Area or Turkey. The Transparency Center website can be queried for any region. Google has confirmed in its developer forums that filtering the website to a specific country will not match the BigQuery tables if those ads never ran in the EEA or Turkey. The dataset also does not give you the ad image, landing page or copy the way the website does, and it can lag the site.

Use BigQuery when you want official, queryable stats for EU/Turkey ads, impression ranges, audience criteria, or removed ads. Use the website (by hand or with a script) when you need another country, or creatives.

-- Ads in the official dataset for one advertiser name (EEA or Turkey only).
SELECT advertiser_verified_name, creative_format, first_shown, last_shown
FROM `bigquery-public-data.google_ads_transparency_center.creative_stats`
WHERE LOWER(advertiser_verified_name) LIKE '%hubspot%'
LIMIT 20

Political ads are a different bundle again (google_political_ads). Do not mix them up with commercial creatives.

Exporting ads for any country

For a lead list or a competitor in the US, the website is the source. Doing that in bulk means paging a JavaScript app that can change without notice.

Google Ads Library Scraper (Ads Transparency Center) is the Cleanrows Actor for that job. Paste a domain, a brand name or an advertiser ID. You get a check (is this company advertising, Google's ad-count range, the advertiser accounts) and, if you want them, one row per ad: format, first and last shown dates, an image or preview, and a link back to the Center. $0.50 per 1,000 ads and $2 per 1,000 checks, no start fee. Not-found lookups are free. Set maxAdsPerQuery to 0 to only run the check.

It does not extract ad copy text. Domain searches can include resellers whose ads point at that domain; use an advertiser ID when you want one account.

    if row.get("type") == "summary":
        print(row["query"], row["is_advertising"], row.get("ads_total_label"))

FAQ

Is the BigQuery dataset an API for the Ads Transparency Center?

It is an official public dataset, not a live API for the website. It is limited to ads shown in the EEA or Turkey, and it does not include the creative assets you see on the site.

Can the Google Ads API list a competitor's ads?

No. The Google Ads API operates on accounts you have access to. Google's own support has said there is no Transparency Center endpoint in that API.

Do I need a Google login to use the Transparency Center website?

You can browse advertisers and ads in a browser without running ads yourself. The BigQuery dataset needs a GCP project.
