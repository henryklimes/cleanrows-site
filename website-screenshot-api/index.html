Website screenshot API in Python — full-page captures, or a hosted option

How to take a full-page website screenshot in Python with Playwright, what usually breaks in bulk, and a pay-per-successful-capture API for PNG, JPEG, WebP or PDF.

For one URL, you do not need an API. Playwright (or Puppeteer) can open a headless browser and write a PNG.

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page(viewport={"width": 1280, "height": 720})
    page.goto("https://example.com", wait_until="networkidle")
    page.screenshot(path="example.png", full_page=True)
    browser.close()

full_page=True scrolls the document and stitches a tall image. For a PDF, use page.pdf(). For a mobile frame, set a smaller viewport or a device descriptor.

What breaks when you do this in bulk

  • Cookie banners and lazy load. A screenshot taken at load will miss images that only appear after a scroll. You often need to dismiss a consent dialog and scroll once before capturing.
  • Timeouts and bot checks. Some sites never go networkidle. Some serve a challenge page to a datacenter IP. One failure should not kill the whole job.
  • Cost of the browser. A Chromium instance per URL is heavy. You will want a pool, a timeout, and a clear "this URL failed" row instead of a crashed process.
  • Formats. PNG is huge for long pages. JPEG or WebP, or a PDF, is usually what people actually wanted when they said "screenshot this list of URLs".

A small Playwright loop is the right tool for a dozen URLs on your laptop. It is a production system once you have hundreds of URLs, mixed desktop and mobile, and a retry policy.

A hosted option

Screenshot & PDF API runs those captures on Apify: PNG, JPEG, WebP or PDF, full-page and device presets, optional selector and wait strategy. You pay $2 per 1,000 successful captures; failed ones are not billed.

import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("henryklimes/screenshot-pdf").call(run_input={
    "urls": ["https://example.com"],
    "outputFormats": ["png"],
    "viewportPreset": "desktop",
    "fullPage": True,
})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row.get("url"), row.get("status"), row.get("file_url"))

Successful rows include a file_url for the capture. Related: URL to PDF API.

FAQ

What is the simplest Python library for a full-page screenshot?

Playwright. Install playwright, run playwright install chromium, and call page.screenshot(full_page=True). Selenium can do it too, but Playwright's API is smaller for this job.

Why is my "full page" screenshot only the first viewport?

The page probably never grew to its full height: lazy-loaded content, a canvas, or a fixed-height body. Scroll to the bottom once, or wait on a specific selector, before you capture.

Can I get a PDF instead of a PNG?

Yes. In Playwright, page.pdf(). In the Cleanrows Actor, set outputFormats to ["pdf"]. See the URL to PDF guide if PDF is the main goal.
