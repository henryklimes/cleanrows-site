Official Google Trends API — alpha access, and what to use until then

Google announced a Trends API in July 2025. It is still an alpha you have to apply for. Here is what it offers, and practical options if you need Trends data today.

On 24 July 2025 Google announced a Google Trends API on the Search Central blog. The developer page, Google Trends API Alpha, still describes it as an alpha and is "accepting applications for alpha testers". This page was checked on 20 November 2026.

What the official API offers

According to Google's own documentation, the alpha includes:

  • a rolling window of the last five years
  • daily, weekly, monthly and yearly aggregation
  • country and sub-region breakdowns
  • consistently scaled values, so you can join requests instead of treating every chart as its own 0–100 scale
  • comparisons of dozens of terms (the Trends website, Google says, lets you compare eight)

If you get in, use it. It is the first-party source, and consistent scaling is the main thing unofficial clients have to fake with anchor keywords.

Google says it prioritises applicants who know what they want to build, can start soon, and will give feedback. Apply on the Trends API page.

If you need the data today

Until you have access, the practical options are:

  • The Trends website for a handful of terms. Fine for one-off research, not for a weekly keyword list.
  • An unofficial Python client that talks to the same explore endpoints the website uses. This is what pytrends did. That library is now unmaintained, and Google often answers HTTP 429. See pytrends 429.
  • A hosted client that holds sessions and retries for you.

FAQ

Can I get a key for the official Google Trends API today?

Only if Google accepts you into the alpha. The public developer page is still an application form, not a self-serve console.

Does the official API return absolute search volumes?

Google says the values are consistently scaled search interest, not raw search counts. That is an improvement on the website's per-request 0–100 scale, but it is still interest, not volume.

How is this different from pytrends?

pytrends (and similar libraries) scrape the website's unofficial endpoints. The official API is a documented product with a different scaling model. pytrends is unmaintained and is often rate-limited.
