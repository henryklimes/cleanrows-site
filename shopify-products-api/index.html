Shopify products API — export a public catalog

Public Shopify stores expose products.json. Here is how to page through a full catalog, what the endpoint leaves out, and a hosted Actor that also covers WooCommerce on one schema.

A public Shopify store usually offers a JSON catalog with no login:

https://{shop}/products.json?limit=250&page={n}

The official Ajax and Storefront APIs exist too, but products.json is the one people reach for when they want prices, variants, images and titles for a competitor store or a price-watch job. The Shopify Ajax API documents the related product endpoints.

Gotchas

  • Page size is capped (commonly 250). Large catalogs need paging until a page comes back empty.
  • Some stores disable or restrict products.json. A 404 here is not "the store has no products."
  • Variant inventory can be missing or rounded, depending on how the merchant configured the storefront.
  • Sale prices, compare-at prices and stock need careful reading of the variant object — they are easy to mix up.
  • This is Shopify only. WooCommerce shops talk a different API.

A short script is fine for one shop. It gets messy when you want many stores, a stable schema, and WooCommerce in the same file.
