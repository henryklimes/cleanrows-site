Scrape a Greenhouse job board to JSON or CSV

Scrape a public Greenhouse job board to JSON or CSV via the official board API, or a hosted Actor that also covers Lever and Ashby.

If you want to "scrape Greenhouse jobs," start with the official public board API, not a headless browser. Greenhouse documents it, and it needs no API key:

https://boards-api.greenhouse.io/v1/boards/{board_token}/jobs

The job board API documentation lists the fields. The list endpoint is enough for titles, locations and apply URLs. Full descriptions usually need a second call to /v1/boards/{board_token}/jobs/{id}. Respect the company's site and Greenhouse's terms; this API exists so job boards and aggregators can read public postings.

What a small script has to get right

  • {board_token} comes from the board URL (boards.greenhouse.io/{token} or job-boards.greenhouse.io/{token}), not necessarily the brand name. If you do not have it, see Does a company use Greenhouse?.
  • The list historically emphasises updated_at. A first-published date is not always present, so "jobs posted this week" is harder than it looks from the list alone.
  • Some companies post the same role once per location, which inflates counts if every row is treated as a unique job.
  • This API is Greenhouse only. Lever, Ashby and Workday each have a different shape.

Write the rows to CSV with the standard library once you have the JSON. For one or two boards that is enough.

FAQ

Do I need a Greenhouse API key to scrape a public board?

No. The public job-board API that powers boards.greenhouse.io pages does not require a key, login or proxy.

Can I get the result as CSV?

Yes. From your own script, write CSV yourself. From the Actor, use the dataset Export menu (CSV, Excel or JSON).

How do I watch only new jobs?

Turn on incremental mode on the Actor, or start from the New jobs at AI companies in the last 7 days task and point it at your boards. Schedule the task daily if you want a feed.
