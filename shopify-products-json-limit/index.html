Shopify products.json 250 limit — how to page a full catalog

Shopify's public products.json endpoint returns at most 250 products per request and ignores a larger limit. How to paginate correctly, when a short page is not the end, and what to do on very large catalogs.

Most public Shopify storefronts expose a catalog as JSON, with no login:

https://{shop}/products.json?limit=250&page={n}

Two limits catch people out.

The page size is 250, and a larger limit is silently clamped. ?limit=500 still returns at most 250 products, usually with HTTP 200. If you omit limit, you often get 30. A loop that stops when "I asked for 500, I got fewer than 500" will exit after page one.

Stop on an empty page, not on a short one. The end of the catalog is {"products": []}. Some stores return pages shorter than 250 before the last page (for example because some products are hidden from the online channel after pagination is applied). If you stop at the first short page, you can miss most of the catalog.

This products.json route is the public storefront feed. It is not the Admin API. Forum advice that "page is deprecated, use page_info" is about the authenticated Admin API. The storefront feed still pages by number, has no Link header, and gives you no total count.

A small script

import requests

def all_products(base):
    page, out = 1, []
    while True:
        r = requests.get(
            f"{base.rstrip('/')}/products.json",
            params={"limit": 250, "page": page},
            timeout=20,
        )
        r.raise_for_status()
        batch = r.json().get("products") or []
        if not batch:
            break
        out.extend(batch)
        page += 1
    return out

A 404 or an HTML body instead of JSON usually means the shop has disabled the feed, not that it has no products. Wait a little between pages; bursts can be rate-limited.

On very large catalogs, stores have been seen returning HTTP 400 once page × limit goes past 25,000, with a message like Page * Limit exceeds the 25000 limit. If you hit that, split the work by collection: list /collections.json, page each /collections/{handle}/products.json, and deduplicate by product id.

Prices are in the shop's base currency, not necessarily the currency a visitor in another country would see. Inventory and sale prices live on the variant object and are easy to mix up.

FAQ

Why do I only get 30 or 250 products from a large Shopify store?

The public feed pages. Without limit you often get 30. With limit=250 you get at most 250 per request, even if you asked for more. Keep incrementing page until a response has an empty products array.

Should I use Shopify's page_info cursor?

That is for the Admin API, which needs the merchant's token. The public /products.json feed still uses page numbers.

What if products.json is 404?

Some shops turn the feed off or put a custom storefront in front of it. Try the shop's collections, or a hosted scraper that can fall back. A 404 is not proof the catalog is empty.
