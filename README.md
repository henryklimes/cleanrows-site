# Cleanrows

Public website for [Cleanrows](https://apify.com/henryklimes), a portfolio of paid Apify Store Actors that return structured rows of public data.

**Live site:** [https://henryklimes.github.io/cleanrows-site/](https://henryklimes.github.io/cleanrows-site/)

This repository holds only the generated static files (guides, data reports, sitemap, RSS and `llms.txt`). Do not edit them by hand. They are published from the private source repo with `marketing/scripts/publish_site.sh`.

Pages is served from the `main` branch, folder `/`. If the live URL is not up yet, enable it once under Settings → Pages → Deploy from a branch → `main` / `/`.
