Lever jobs API — public postings as JSON

Lever's public postings endpoint needs no API key. Here is the URL, the mode=json flag, and a hosted way to map Lever jobs onto the same schema as Greenhouse and Ashby.

Lever publishes a public postings API for companies that use Lever as their applicant tracking system. No API key is required:

https://api.lever.co/v0/postings/{company}?mode=json

{company} is the slug in the company's Lever careers URL, for example https://jobs.lever.co/spotify becomes spotify. Without mode=json you often get HTML instead of the list of postings.

Gotchas

  • The slug is not always the legal company name, and a rebrand can change it.
  • Each posting has its own location text. Remote roles are not always flagged with a boolean; you have to read the location or description.
  • Lever is only one ATS. A recruiting feed that also covers Greenhouse and Ashby has to normalise three different payloads.

If you only need one company's board, a short script is enough. If you want one schema across many companies and several ATS platforms, a hosted feed saves you the mapping work.

The Actor

ATS Jobs Feed accepts Lever company slugs alongside Greenhouse, Ashby, Workable, SmartRecruiters and Recruitee boards, and returns the same columns for all of them. $1.50 per 1,000 jobs, no start fee.
