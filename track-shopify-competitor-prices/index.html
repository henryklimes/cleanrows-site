Track competitor prices on Shopify stores

Watch competitor prices on Shopify with the public products.json feed: sale prices, stock and variants, on a schedule.

Most public Shopify stores expose a catalog feed at /products.json. You do not need a Shopify Partner account or a storefront password (password-protected stores will not answer). Each product includes variants, prices, compare-at prices, SKUs, tags, images and an availability flag. That is enough to track a competitor's list price and sale price without browsing the site.

A DIY monitor

  1. Confirm the shop is Shopify (the HTML often has cdn.shopify.com, or /products.json returns JSON).
  2. Page /products.json?limit=250&page=N. The ceiling is 250 products per page even if you ask for 500; there is also an offset cap on very large catalogs. The Shopify products.json 250 limit guide covers both.
  3. Store id / variant id, price, compare_at_price and inventory as a snapshot.
  4. Run the same job tomorrow and diff on variant id. Schedule a cron, and keep a polite delay between pages.

This breaks down when you also want WooCommerce shops in the same table, when a catalog is huge, or when you do not want to maintain paging and retries yourself. The official Admin API is the right tool when you own the store and have a key; it is the wrong tool for a competitor's public storefront.

FAQ

Do I need API access to the Shopify store?

No. The public products.json endpoint that most Shopify stores expose needs no login or API key. Private or password-gated shops will not return the catalog.

Can I watch only one collection?

Yes. The Export one Shopify collection task is set up for a single collection URL rather than the whole catalog.

How often should I schedule a price check?

Daily is enough for most retail catalogs and is gentler on the store. Hourly is rarely worth it unless prices actually change that fast.
