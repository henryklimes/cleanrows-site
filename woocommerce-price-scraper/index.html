WooCommerce price scraper — export a public catalog

Export prices, sale prices, variants and stock from a public WooCommerce store with the Store API, or a hosted scraper.

A public WooCommerce store usually exposes its catalog through the Store API: /wp-json/wc/store/v1/products. No customer login and no REST API key are required for that public route. (The Admin REST API is a different, authenticated interface meant for the store owner.)

Each product carries regular and sale prices, currency, stock status, images, categories and, if you request them, variations. That is the data a price scraper actually needs.

DIY, briefly

Page the Store API (page and per_page, typically up to 100), keep a delay, and write SKU, price, sale price and stock to CSV. Variations are a second request per variable product; skipping them under-counts SKUs on clothing and furniture shops.

Stores can disable the Store API, hide prices until login, or put the shop on a separate subdomain. If /wp-json/wc/store/v1/products 404s, there is no public catalog to scrape, and a browser crawl is a different, heavier project.

FAQ

Do I need a WooCommerce API key to export prices?

Not for a public store that exposes the Store API. The Admin REST API does need keys, and it is the right choice only when you own the shop.

Can I get every size and colour, not just the parent product?

Yes. Use the variations task, or turn on variation fetching. Each variant has its own price and stock.

What does it cost?

The Actor charges $1 per 1,000 products (variants count as products when you fetch them).
