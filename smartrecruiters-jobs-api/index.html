SmartRecruiters jobs API — public postings, paged with offset

SmartRecruiters publishes a public postings API that needs no key. It pages with limit and offset, and the list payload does not include the full job description. Here is a working request, and a hosted feed for mixed ATS boards.

A company's SmartRecruiters board is usually at https://careers.smartrecruiters.com/{companyIdentifier}. The public postings API is:

GET https://api.smartrecruiters.com/v1/companies/{companyIdentifier}/postings?limit=100&offset=0

No API key. The JSON includes offset, limit, totalFound and a content array. Increase offset by the page size until offset reaches totalFound, or until a page comes back empty. A limit of 100 is a reasonable page size; do not assume one request is the whole board.

On 20 November 2026, DeliveryHero returned totalFound of 790 postings. The first item on that board had a title, location (city, region, country, remote/hybrid flags), department, function, employment type and releasedDate. It did not include a jobAd or job description. The list endpoint is a catalog. If you need the full text, you have to request each posting separately (the apply URL is https://careers.smartrecruiters.com/{companyIdentifier}/{id}).

Unknown or empty identifiers often still return HTTP 200 with totalFound: 0. Check the count, not only the status code.

import requests

company = "DeliveryHero"
offset, limit, jobs = 0, 100, []
while True:
    data = requests.get(
        f"https://api.smartrecruiters.com/v1/companies/{company}/postings",
        params={"limit": limit, "offset": offset},
        timeout=20,
    ).json()
    page = data.get("content") or []
    jobs.extend(page)
    offset += len(page)
    total = data.get("totalFound", offset)
    if not page or offset >= total:
        break

for job in jobs[:10]:
    loc = job.get("location") or {}
    print(job["name"], loc.get("fullLocation") or loc.get("city"), job.get("releasedDate"))

There is usually no structured salary field on this endpoint. Pace your requests if you walk a large board.

FAQ

Why do I only see 100 SmartRecruiters jobs?

The API pages. Pass limit and keep moving offset until you have totalFound rows, or until a page is empty.

Why are job descriptions missing?

The public list response we received did not include jobAd or description text. Plan a second request per posting if you need the full ad.

How do I find the company identifier?

It is the first path segment after careers.smartrecruiters.com/ or jobs.smartrecruiters.com/. It is case-sensitive on some boards (for example DeliveryHero).
