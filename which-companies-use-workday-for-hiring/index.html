Which companies use Workday for hiring?

How to recognise a Workday career site on myworkdayjobs.com and look up which companies use it for hiring.

"Which companies use Workday for hiring?" and "which big companies use Workday" are common searches. Workday is an HR suite; the career sites job-seekers actually see usually live on {tenant}.wd{N}.myworkdayjobs.com/{site}. That is a different question from "who uses Workday HCM for payroll," and a company can use Workday internally without a public myworkdayjobs.com board.

How to recognise a Workday jobs site

Open a live job and look at the address:

  • Host pattern: nvidia.wd5.myworkdayjobs.com, salesforce.wd12.myworkdayjobs.com — the wd number is a data centre, not a version you need to guess for long.
  • Path: a site name such as NVIDIAExternalCareerSite or CorporateCareers, sometimes with an en-US locale prefix.
  • The apply form stays on that host. A "Powered by Workday" line sometimes appears, but the host is the reliable signal.

NVIDIA, Salesforce and Adobe are current public examples on myworkdayjobs.com. Re-check the live URL; employers do move.

If you only have a company name, the careers link on the corporate site usually redirects to the Workday host. Guessing {company}.wd5.myworkdayjobs.com is unreliable: the tenant, the wd number and the site name all vary.

FAQ

Do all large companies use Workday to hire?

No. Workday is common at enterprises, but many still use iCIMS, a custom site, or a mix by country and role type. Check the Apply URL or run a domain lookup.

Is "uses Workday" the same as a myworkdayjobs.com career site?

Not always. Workday HCM can run payroll or HR without a public Workday job board. For recruiting data, look for the myworkdayjobs.com (or occasional myworkdaysite.com) host.

Can I get salary ranges from Workday postings?

When the employer publishes them, yes. The Extract salary ranges from Workday job postings task is set up for that.
