WooCommerce products API — export a public store catalog

The WooCommerce Store API can return products without a consumer key on many public shops. Here is the endpoint, the usual traps, and a hosted Actor that also covers Shopify.

Many WooCommerce shops expose the Store API without a customer login or a REST consumer key:

https://{shop}/wp-json/wc/store/v1/products

That is a different endpoint from the password-protected WooCommerce REST API (/wp-json/wc/v3/products). If you only need what a shopper can already see — title, price, stock status, images, variations — the Store API is the one to try first.

Gotchas

  • Not every shop leaves the Store API open. A 401 or 404 means you should stop, not guess admin credentials.
  • Paging uses page and per_page (capped). You have to walk until a short page.
  • Variation prices and sale prices sit in slightly different fields than Shopify's products.json.
  • Some sites sit behind a firewall or a bot challenge that a simple GET will not pass.
