Recruitee jobs API — export a public board to JSON

Recruitee publishes a free, keyless jobs API at /api/offers. Here is the endpoint, what it returns, and a hosted Actor that maps Recruitee openings onto the same schema as Greenhouse and Lever.

Recruitee gives every company a public job board API. You do not need a key:

https://{company}.recruitee.com/api/offers

The JSON body has an offers array. Typical fields are id, title, department, location, employment_type, remote, description, careers_url, created_at and updated_at. One request usually returns the whole board; there is no official pagination to walk.

Gotchas

  • The {company} token is the Recruitee subdomain, not always the brand. Read it from the careers URL (acme.recruitee.com or a recruitee.com/acme path).
  • A 404 means that subdomain does not exist, or the board is not public. Treat it as "no board", not as "zero jobs".
  • Descriptions often arrive as HTML. Salary, when it is present at all, is usually inside that HTML rather than a structured field.
  • This API only covers Recruitee. Greenhouse, Lever, Ashby, Workable and SmartRecruiters each have a different shape.

A short Python script is enough for one board. The work starts when you want many boards, a stable schema, and the same columns from the other applicant tracking systems.

One schema with the other ATS boards

ATS Jobs Feed pulls Recruitee, Greenhouse, Lever, Ashby, Workable and SmartRecruiters into one JSON or CSV feed: title, company, location, salary when the company publishes one, apply URL, and optional description. It costs $1.50 per 1,000 jobs, with no start fee.

import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("henryklimes/ats-jobs-feed").call(run_input={
    "companies": [
        {"name": "Example", "ats": "recruitee", "identifier": "example"},
    ],
    "includeDescription": True,
})
for job in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(job["title"], job["location"], job["apply_url"])

If you only have a company domain and not the Recruitee slug, Careers Page & ATS Detector can find the board ID first. For Greenhouse, Lever and Ashby see the Greenhouse, Lever and Ashby guides.

FAQ

Do I need a Recruitee API key?

Not for the public board. https://{company}.recruitee.com/api/offers is unauthenticated. Recruitee's private recruiting API is a different product and does need credentials; this page is only about the public offers list.

How do I find the company slug?

It is the subdomain of the careers site (slug.recruitee.com) or the first path segment on recruitee.com/slug. Guessing from the brand name is unreliable.

Does the endpoint page results?

In practice the public offers endpoint returns the whole board in one response. If a request fails, retry the same URL; there is no documented limit/offset contract to walk.
