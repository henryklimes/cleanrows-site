Export Google Trends data to CSV in bulk

Export Google Trends interest over time to CSV for many keywords, including comparisons of more than five terms on one 0–100 scale.

Google Trends lets you download a CSV for a single explore view, and that is the right first step: open the chart, use the download icon, and you get interest over time for up to five compared terms. The pain starts when you have 50 keywords, want a daily refresh, or need more than five (or eight) terms on one 0–100 scale.

What the website already gives you

  • Interest over time, interest by region, related queries and related topics, for a geo and date range you pick.
  • A CSV per view, for up to five terms in a comparison (eight in some Trends UIs).
  • Trending Now and a public RSS feed per country, which is a different product from interest-over-time.

Pasting keywords by hand does not scale, and each Explore download is a separate file you then have to join. The unofficial pytrends library used to automate this; it is archived, and it often dies with HTTP 429. See pytrends alternative and pytrends 429 error if that is the road you are on. Google's official Trends API is still an alpha with an application process, not a generally available export button.

Bulk export

Google Trends API & Scraper – Bulk Keywords, Compare, Trending holds the sessions, paces requests, retries, and can chain comparison batches so more than five terms share one scale. It costs $0.25 per 1,000 keyword-rows and $0.10 per 1,000 Trending Now rows, with no start fee. Failed and no_data rows are not charged. After a run, export the dataset as CSV or Excel.

Example tasks:

  • Compare more than 5 keywords in Google Trends
  • Keyword research with rising Google Trends queries
  • Google Trends for the last 7 days (hourly)

How the compare math works is in Compare more than 5 Google Trends keywords. Related queries, including Breakout terms, are in Google Trends related queries.

FAQ

Can I download Google Trends as CSV without writing code?

Yes. Run one of the example tasks in Apify Console and use the dataset Export menu. You can also still download a single five-term comparison from the Trends website itself.

How do I put 20 keywords on one scale?

Use compare mode on the Actor (or the compare-more-than-5 task). It anchors batches so the 0–100 values are comparable. A plain loop of single-keyword Explore downloads is not on one scale.

Can I export Trends by US state, or YouTube search?

Yes. See Google Trends interest by US state and YouTube search trends.
