Does a company use Greenhouse? How to check

How to tell whether a company hires on Greenhouse, Lever, Ashby or another ATS, from one Apply URL or a list of domains.

"Does this company use Greenhouse?" is the usual follow-up once you have a domain and want to pull its jobs, tailor a CV, or build a hiring-signal list. Greenhouse is common at startups and scale-ups, but it is not the only system, and the board token is not always the brand name.

A one-company check

  1. Open the careers page and click a live job, then Apply.
  2. If the address is boards.greenhouse.io/{token} or job-boards.greenhouse.io/{token}, it is Greenhouse. {token} is the board ID you need for the API.
  3. Confirm with a request to the public board API (no key): https://boards-api.greenhouse.io/v1/boards/{token}/jobs. A JSON list of jobs means the board is live. An error means the token is wrong or the board is not public.
  4. If the host is jobs.lever.co, jobs.ashbyhq.com or *.myworkdayjobs.com, the company is not on Greenhouse for that job — see Which ATS does a company use?.

Stripe is a current public example: the board at job-boards.greenhouse.io/stripe answers on the Greenhouse API. That can change; believe the live URL.

Embedded boards are easy to miss. A company can list jobs on its own domain and still load Greenhouse in the page (gh_jid= in links, or a greenhouse.io script). Search the source if the Apply URL stays on-site.

Checking a list of companies

For more than a handful of domains, Careers Page & ATS Detector returns the ATS name, board ID, careers URL and open-job count. $3 per 1,000 domains. FAQ

Does every company with a "Careers" page use Greenhouse?

No. Greenhouse is one of many systems. Workday is common at large enterprises, Ashby and Lever at startups. Always read the Apply host or call the Detector.

Is the Greenhouse board token the company name?

Not always. It is the token in the board URL. Guessing greenhouse:acme fails often enough that you should confirm with the API or a detector run.

Can I get the jobs once I know it is Greenhouse?

Yes. The public board API returns titles, locations and apply links. Scrape a Greenhouse job board walks through that, and the Greenhouse jobs API guide covers the official endpoints.
