Greenhouse jobs API — export a public board to JSON

Greenhouse publishes a free job-board API. Here is the endpoint, what it does and does not return, and a hosted Actor that maps Greenhouse jobs onto the same schema as Lever and Ashby.

Greenhouse gives every company a public job board API. You do not need a key:

https://boards-api.greenhouse.io/v1/boards/{board_token}/jobs

The job board API documentation describes the fields. The list endpoint is enough for titles, locations and apply URLs. Full descriptions usually need a second call to /v1/boards/{board_token}/jobs/{id}.

Gotchas

  • The {board_token} is not always the company name. It is the token in the board URL (boards.greenhouse.io/{token}).
  • The list endpoint historically emphasised an updated_at timestamp. A first-published date is not always present, so "jobs posted this week" is harder than it looks if you only have the list.
  • Some companies post the same role once per location, which inflates counts if you treat every row as a unique job.
  • This API only covers Greenhouse. Lever, Ashby and Workday each have a different shape.

A 30-line Python script is enough for one board. The work starts when you want many boards, a stable schema, and the same columns from other applicant tracking systems.
