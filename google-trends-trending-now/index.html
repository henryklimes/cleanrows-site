Google Trends Trending Now API — daily trending searches

Google publishes a public Trending Now RSS feed per country, with around 10 rising searches, approximate traffic and news. How to read it for free, and a hosted Actor if you want a scheduled history.

Google Trends Trending Now lists searches that are rising right now in a country. It is not the same as interest-over-time for a keyword you already picked: you do not choose the terms, Google does. The public feed is enough for a daily digest. It does not, by itself, keep history.

What to try for free

Google still publishes a public RSS feed, one country at a time:

https://trends.google.com/trending/rss?geo=US

Replace US with another country code (GB, DE, CZ). Each item is a trending search, usually with approximate traffic (for example 20000+), a start time, a picture and a few related news links. A 20-line Python script with feedparser or the standard library can turn that XML into rows.

Limits of the free feed:

  • Google currently lists about 10 searches per country, not a long tail.
  • The feed is a snapshot. If you want yesterday's list, you have to have saved it yourself.
  • It is per country, not worldwide and not per US state.
  • Approximate traffic is a bucket, not an exact count.

For a morning briefing in one country, the RSS feed is the right tool.

A hosted option

If you want the same feed as structured rows, for several countries, on a schedule that builds your own history, Google Trends API & Scraper – Bulk Keywords, Compare, Trending has a trendingNow mode. It returns title, approx_traffic, started_at, picture and news. Price: $0.10 per 1,000 Trending Now rows, no start fee.

import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])
run = client.actor("henryklimes/google-trends").call(run_input={
    "mode": "trendingNow",
    "geos": ["US", "GB", "DE"],
    "maxTrendingItems": 20,
})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row["geo"], row["rank"], row["title"], row.get("approx_traffic"))

Interest over time, related queries and comparisons of more than five keywords are separate modes of the same Actor. See the Google Trends API guide.

FAQ

Is Trending Now an official API?

No. The RSS feed is a public Google Trends URL, not the official Trends API alpha. There is no key and no SLA. The feed can change shape.

How many trending searches do I get per country?

The live Google feed is currently about 10 items per country. Asking for more than that will not invent extra rows.

Can I get worldwide Trending Now, or a US state?

No. The feed is per country code. Worldwide and sub-regions are not available in this mode.
