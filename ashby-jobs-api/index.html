Ashby jobs API — public job board postings

Ashby exposes a public posting API for company job boards. Here is the endpoint, how it differs from Greenhouse and Lever, and a hosted Actor that maps them onto one schema.

Ashby provides a public job-board API for companies that host their careers page on Ashby. No API key is required:

https://api.ashbyhq.com/posting-api/job-board/{board}

{board} is the token in the Ashby hosted board URL. OpenAI, Ramp, Notion, Plaid and a growing list of startups publish this way.

What is nice about Ashby

Ashby includes a publish date on each posting. That makes "roles opened in the last 7 days" a real query, which Greenhouse's public list endpoint does not always support cleanly. If you are measuring hiring velocity, Ashby boards are the easy case.

Gotchas

  • The board token is not always the brand name you expect.
  • Some companies move off Ashby, or the board starts showing a different company name after an acquisition or rename. Always store the board token, not only the display name.
  • Ashby is still only one ATS. Greenhouse, Lever and Workday will appear in the same prospect list.
